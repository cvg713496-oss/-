# 🎬 Vocal Studio V1.0 - កម្មវិធីសម្រាយរឿង និងបញ្ចូលសម្លេង (ចិន ➔ ខ្មែរ)

កម្មវិធីសម្រាយរឿង និងបញ្ចូលសម្លេងស្វ័យប្រវត្តិតាមរយៈ AI ដែលត្រូវបានបង្កើតឡើងជាពិសេសសម្រាប់អ្នកធ្វើមាតិកា **សម្រាយរឿងចិន (Movie Recap)** លើ YouTube, TikTok, Facebook Reels។

---

## 🌟 លក្ខណៈពិសេសសំខាន់ៗ (Features)

1. **ស្រង់សម្លេងចិនស្វ័យប្រវត្តិ (Whisper Speech-to-Text)**
   - គាំទ្រ Whisper AI Model គ្រប់កម្រិត (Tiny, Base, Small, Medium)
   - ចាប់យកពេលវេលាជាក់លាក់ (Start Time, End Time) និងឃ្លានិយាយភាសាចិនបានច្បាស់លាស់។

2. **បកប្រែ និងសម្រាយជាភាសាខ្មែរ (Chinese ➔ Khmer Movie Recap)**
   - បកប្រែភាសាចិនមកខ្មែរដោយស្វ័យប្រវត្តិ
   - អាចកែសម្រួលអត្ថបទសម្រាយខ្មែរក្នុងតារាងបានភ្លាមៗ (Inline Table Editor)

3. **បញ្ចូលសម្លេងខ្មែរធម្មជាតិ (Neural Khmer TTS Dubbing)**
   - គាំទ្រសម្លេង Microsoft Edge Neural Khmer ច្បាស់ពិរោះ៖
     - `km-KH-PisethNeural` (សម្លេងប្រុស / តួប្រុស ឬអ្នកសម្រាយ)
     - `km-KH-SreymomNeural` (សម្លេងស្រី / តួស្រី)
   - អាចចុចស្តាប់សម្លេងសាកល្បងមុនពេល Export (Play Preview per line)
   - កែសម្រួលល្បឿននិយាយ (Speed: -10%, +0%, +10%, +20%)

4. **Multi-Track Timeline & Live Video Preview**
   - បន្ទាត់ពេលវេលា Timeline ពហុតួអង្គ (ពណ៌បៃតងសម្រាប់តួប្រុស, ពណ៌ស្វាយសម្រាប់តួស្រី)
   - ចុចលើ Segment ណាមួយ វីដេអូនឹង Jump ទៅវិនាទីនោះភ្លាម
   - Sync Subtitle និង Cursor រត់តាមវីដេអូជាក់ស្តែង

5. **តន្ត្រីផ្ទៃក្រោយ (BGM) & សម្លេងដើម (Audio Mixing)**
   - អាចដាក់ភ្លេង BGM អមវីដេអូ និងបន្ថយកម្រិតសម្លេងដើមចិន (Background SFX)
   - Auto-mixing រៀបចំសម្លេងនិយាយខ្មែរចំវិនាទីនៃវីដេអូដើម

6. **Watermark & Subtitles Burn-in (Hardsub)**
   - ដាក់ឈ្មោះ Channel / Watermark នៅលើវីដេអូ
   - ដុតអក្សររត់ Subtitle ភាសាខ្មែរ (Font ច្បាស់ មានស្រមោល និងស៊ុមខ្មៅ)

7. **Export វីដេអូសម្រេច**
   - Render ចេញជាវីដេអូ MP4 កម្រិតខ្ពស់ អាច Upload ទៅកាន់បណ្តាញសង្គមភ្លាមៗ។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### វិធីទី១៖ ងាយស្រួលបំផុត (Double Click)
ចុចពីរដង (Double click) លើឯកសារ៖
```
run_app.bat
```
កម្មវិធីនឹងបើកផ្ទាំង Browser ដោយស្វ័យប្រវត្តិនៅអាសយដ្ឋាន `http://127.0.0.1:8000` ។

### វិធីទី២៖ ដំណើរការតាម Command Line
```powershell
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```
បន្ទាប់មកបើក Browser ចូលទៅកាន់ `http://127.0.0.1:8000` ។

## 📖 របៀបប្រើប្រាស់ (Step-by-step Workflow)

1. **ជ្រើសរើសវីដេអូ**៖ ចុចលើប៊ូតុង `📁 Add Video` ដើម្បីជ្រើសរើសវីដេអូចិនដែលអ្នកចង់សម្រាយ (ឬចុច `✨ Load Demo` ដើម្បីសាកល្បងវីដេអូគំរូ)។
2. **ស្រង់សម្លេងចិន**៖ ចុចលើប៊ូតុង `⚡ Transcribe (ចិន)` ដើម្បីឱ្យ Whisper AI ចាប់យកសម្លេងនិងពេលវេលានិយាយ។
3. **បកប្រែជាភាសាខ្មែរ**៖ ចុចលើប៊ូតុង `🌐 Translate (ខ្មែរ)`។
4. **កែសម្រួល & បែងចែកសម្លេង**៖
   - អ្នកអាចកែសម្រួលពាក្យសម្រាយក្នុងប្រអប់អត្ថបទខ្មែរឱ្យកាន់តែទាក់ទាញ
   - ចុចប៊ូតុង `▶` ដើម្បីស្តាប់សម្លេងសាកល្បង
   - ចុចលើ `👥 Assign Voice` ដើម្បីកំណត់ថាតើជួរណាជាសម្លេងប្រុស ឬស្រី
5. **បន្ថែម BGM & Watermark**៖
   - ចុច `🎵 Audio BG` ដើម្បីបញ្ចូលភ្លេងកំដរ
   - ចុច `💧 Watermark` ដើម្បីដាក់ឈ្មោះ Channel របស់អ្នក
6. **Export វីដេអូ**៖ ចុចប៊ូតុង `🎬 Export Video` ដើម្បីបង្កើតវីដេអូ Dubbed រួចរាល់!
